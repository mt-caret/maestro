# maestro

The coding and documentation style guide for this repository is [`AGENTS.md`](AGENTS.md).
It is the single source of truth — read it before changing code, and run its
"Before handoff" review over your diff before you hand work off. A subdirectory with its
own `AGENTS.md` overrides it locally.

`PLAN.md` describes the architecture and library layering.
